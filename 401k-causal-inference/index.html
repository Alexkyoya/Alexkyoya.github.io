Does a 401(k) Make People Save More?

A causal study estimating the effect of 401(k) eligibility on household savings using observational data and quasi-experimental techniques. The headline result is that raw savings differences overstate the true effect because a large portion is explained by confounding factors.

Estimated causal effect $4,100–$8,200
Raw gap before adjustment $19,559
Top-quintile benefit ≈$20,100

What the study finds

  • More than half of the apparent savings gap is due to confounding variables rather than the effect of 401(k) access itself.
  • Results are consistent across multiple refutation tests and remain concentrated in higher-income households.
  • We estimate participation value using an instrumental-variable approach, producing a meaningful estimate of the economic payoff from program uptake.
